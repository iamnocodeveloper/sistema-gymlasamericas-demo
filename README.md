# Sistema de membresías · Gym Las Américas Hatillo (demo)

Demo navegable de control de membresías, cobros, accesos y clases para un gimnasio
de Hatillo, San José. Una sola página (`index.html`) sin dependencias externas:
CSS y JavaScript en línea, datos de ejemplo generados en el navegador.

- Recorrido guiado de 8 pasos (teclado: ← →, Esc; modo automático).
- Panel del día, socios con ficha, vencimientos con recordatorio de WhatsApp
  (maqueta, no envía nada), cobros con comprobante, acceso con alerta de
  membresía vencida, agenda de clases e informes en SVG.

Demo de referencia hecho por Nocodeveloper. Los datos son de ejemplo.
